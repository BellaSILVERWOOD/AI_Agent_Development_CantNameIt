把字体文件放进这个文件夹（assets/fonts/），Lumina 启动时会自动加载，
不需要把字体装进系统。支持 .ttf / .otf / .ttc / .otc。

放进来之后，到「设置 → 外观 → 字体」的下拉框里就能选到它们。

关于苹方（PingFang SC）
----------------------
苹方是苹果的商用系统字体，只授权在 Apple 设备上使用，网上流传的
"苹方 Windows 版" 大多违反授权，有的还夹带捆绑程序，不建议下载。

几种更稳妥的做法：
1. 用「设置 → 字体 → 鸿蒙黑体 + Segoe UI Variable」（默认就是这套近似方案），
   观感与苹方 / SF Pro 最接近；
2. 用思源黑体（Noto Sans SC，系统已装）+ Segoe UI；
3. 如果你有 Mac，可以把 macOS 自带的 PingFang.ttc 拷到这台电脑自用
   （仅限个人使用，仍受苹果授权限制），放进本文件夹即可被 Lumina 识别。

免费、可自由使用的近似字体（自行下载后放进本文件夹）：
* 思源黑体 / Source Han Sans（SIL OFL）
* MiSans（小米，免费商用）
* OPPO Sans（免费商用）
* 阿里巴巴普惠体（免费商用）
* HarmonyOS Sans（华为，免费商用）
