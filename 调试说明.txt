DanLume 源码版的三个双击入口
================================

1) 启动 DanLume.bat
   正常启动。窗口会一直开着，程序的提示和报错都显示在里面。
   （关掉这个黑窗口 = 关掉程序）

2) 启动 DanLume（调试）.bat
   带 --debug 启动：除了窗口里的输出，还会把日志写到
       data\logs\lumina-年月日.log
   程序崩了会把 traceback 也写进去，并且弹窗告诉你在哪个文件。
   遇到问题时优先用这个启动，然后把日志发出来。

3) 诊断.bat
   不开界面，直接打印一份诊断报告：程序目录 / 数据目录 / 数据库是否正常 /
   本机账户列表 / 「记住设备」状态 / 登录失败计数 / 设置项（密码、密钥、API Key
   都会打码）/ 最近的日志。
   跑完在 data\diagnostics\ 下生成一个
       DanLume诊断包-年月日-时分秒.zip
   直接把这个 zip 发给帮忙排查的同学就行（里面是脱敏的，不含密码和私钥）。

命令行等价写法
--------------
    python main.py                 # 正常启动
    python main.py --debug         # 带日志启动
    python main.py --diagnose      # 只打印诊断报告
    python main.py --diagnose --export   # 打印并生成诊断包

常见问题
--------
* 双击就闪退：说明少依赖或报错了。请改用「启动 DanLume（调试）.bat」，
  窗口会停住并显示错误；仍看不到就把 data\logs\ 里的日志发出来。
* 「没有这个账户」：先跑「诊断.bat」，看报告第 1 段（数据目录）和第 4 段
  （账户列表）。如果账户列表是空的，说明程序读的不是你以为的那份数据 ——
  多半是复制了一份程序、数据目录跟着变了。报告里会写明它到底在用哪个目录。
* 想让数据放在别处：设环境变量 LUMINA_DATA_DIR 指向那个目录再启动。
