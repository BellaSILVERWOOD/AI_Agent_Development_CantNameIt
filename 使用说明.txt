DanLume · 日程与汇报　使用说明
================================

一、这是「客户端版」
--------------------
这份安装包是给普通用户用的（程序根目录有 client_only.flag 和 admin_pub.pem）。
客户端版**不能自己新建账户**，必须向管理员申请注册：

  1. 打开 DanLume →「注册账户」
  2. 填用户名 + 学校邮箱（必须以 @m.fudan.edu.cn 或 @fudan.edu.cn 结尾）
  3. 点「发送注册申请」
     · 如果这台电脑配过发件邮箱，会自动发出；
     · 没配也没关系：窗口里会给出一整段申请内容，复制后用你自己的邮箱
       发到管理员的邮箱（注册页面上会显示具体地址，按那个发就行）
  4. 管理员批准后，你会收到一封邮件，里面有「6 位验证码」和一行
     以 LUMINA-RECEIPT1. 开头的「回执」
  5. 回到注册窗口：填验证码、粘贴回执 →「验证验证码与回执」→ 设置密码 → 完成

第一次登录后，如果账户还有效，程序会让你选「记住这台设备」24 / 48 小时，
期内打开不用再输密码；到期后需要重新输入。

二、用管理员的模型接口要单独申请
--------------------------------
如果你在 设置 → AI 接口 里选的是管理员的模型地址（例如 10.137.44.215），
要先点「申请模型接口权限」；管理员批准后把邮件里以 LUMINA-GRANT1. 开头的
授权粘回来。一次最多 5 小时，到期要重新申请。

三、怎么启动
------------
方式 A（免安装，推荐）：解压后双击文件夹里的 DanLume.exe。
方式 B（源码运行）：装好 Python 3.9+ 后
    pip install -r requirements.txt
    python main.py

数据都放在 exe / main.py 同级的 data\ 目录里（数据库、登录状态、缓存），
换电脑或重装时把这个目录一起带走就能恢复。

四、注意事项
------------
· 账户密码只存在本机，保存的是 PBKDF2 加盐哈希，任何界面都看不到原文；
· 「忘记密码」只能清空账户重新申请（日程 / 邮件等数据不会删）；
· 程序会定期把使用情况（时长、调用次数、首字延迟、出字速度）发到管理员的
  接收程序；如果连着几次异常，管理员会提醒 / 警告 / 封号；
· 使用情况上报走局域网直连，不需要邮件；如果连不上管理员，界面上会提示。

五、这次新加的功能（还没经过全量测试，出问题请告诉我）
--------------------------------------------------------
1. 右侧多了「文献」标签：搜 arXiv / Crossref / Semantic Scholar，
   结果可多选（全选 / 全不选），能展开看摘要；
   勾选后「一键下载」会存进左侧「文献库」，「一键引用」复制 GB/T 7714 引用。
2. 左侧多了「文献库」页：按「项目 / 年份」分好文件夹，可搜索、可看摘要，
   也能复制整篇文章的引用、复制某个项目的全部引用。
3. EndNote：装了的话「导出 EndNote」会直接打开 .enw；
   没装会问你要不要经 ehall 装（正版软件里找 EndNote）。
4. AI 能做的事变多了（在 设置 → AI 接口 → 工具审核 里可以逐个开/关）：
   · 上网搜资料、找课程视频（B 站 / 中国大学 MOOC / YouTube）；
   · 找课件时会先翻 eLearning 里你自己的课程文件；
   · 能读本机文件（默认只在 data\agent_workspace 里，工作区外的操作每次都会问你）；
   · 能记备忘、加倒计时、开专注计时、看文献。
5. 「删除文件」一律不真删：改名为 [discarded] 原名，并告诉你去哪个目录彻底删。
6. 改了的东西：窗口不透明度默认 98%；标签页的 × 改成灰色（没有红底）；
   eHall 网页里的「进入服务」这类新窗口链接现在能点开了。
